# Movie & TV Streaming Platform

A movie and TV discovery platform powered by the [TMDB API](https://www.themoviedb.org/documentation/api). The website allows users to search and browse movies and TV shows, view information and metadata, and access playback through embedded third-party services.

## Features

* Search for movies and TV shows using TMDB
* Browse movie and TV show information
* View posters, descriptions, ratings, release information, and other metadata
* Watch content through third-party embedded players
* Responsive web interface

## Content & Hosting

This project does **not** host, upload, or store movie or TV video files on its own servers. Video playback, where available, is provided through external third-party services and embedded players.

The project primarily acts as a discovery and interface layer for movie and TV information. Users are responsible for complying with applicable laws and the terms of any third-party services they use.
